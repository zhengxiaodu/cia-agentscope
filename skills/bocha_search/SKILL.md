# 博查网络搜索（Bocha Web Search）

通过调用博查 Web Search API，传入搜索关键词，返回**格式化搜索结果文本**与**来源摘要**。适用于实时资讯查询、时效性事实检索、需要网络证据支持的回答等场景。

**重要**：搜索服务的地址与 API key 由系统在宿主侧自动配置（环境变量），调用方无需（也无法）指定。模型只需传入搜索关键词。

---

## 1. 何时调用

- 用户询问最新消息、实时数据（今日新闻、天气、股价、汇率、体育赛事比分等）
- 用户的问题涉及时效性事实，模型自身知识可能过期时
- 回答需要可引用的网络来源作为证据时

### 不适用场景

- 通用百科知识问答（模型自身知识即可回答）
- 制度、政策、规范类知识库检索（使用 `policy_qa` 工具）
- 用户已提供充分材料的问题（无需额外检索）

---

## 2. 工具信息

| 项目 | 说明 |
|------|------|
| **工具名称** | `bocha_web_search` |
| **调用方式** | 阻塞（Blocking）：等待完整搜索结果返回，不流式 |
| **鉴权方式** | 无（API key 由宿主环境变量持有，模型不可见） |
| **来源摘要** | 自动随结果返回（`bocha_sum`），前端可直接展示引用来源 |
| **是否落库** | 是：来源摘要随 assistant 消息写入会话历史 |
| **超时控制** | 15s（超时返回友好提示，不中断回答） |

---

## 3. 工具参数

### 入参

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `query` | `string` | 是 | 搜索关键词，简洁明了，至少 1 个字符 |

> **说明**：其余请求参数（结果数量、Freshness 等）均使用博查服务默认值，模型无需也无法指定。

### 调用示例

```
用户: 今天有什么科技新闻？
Agent: 调用工具 bocha_web_search，传入 query="今日科技新闻"
```

---

## 4. 返回格式

工具返回一段格式化文本，包含**搜索结果列表**：

```
[1] 标题一
摘要或片段内容
链接: https://example.com/page1
[2] 标题二
摘要或片段内容
链接: https://example.com/page2
```

### 来源摘要（bocha_sum）

每条来源自动附带以下字段，随事件流发送到前端并在会话历史中展示：

- `name`：网页标题
- `url`：网页链接
- `snippet`：内容片段
- `summary`：内容摘要
- `siteName`：站点名称
- `datePublished`：发布日期

---

## 5. 错误处理

| 场景 | 返回内容 |
|------|---------|
| 关键词为空 | `"错误：搜索关键词不能为空。"` |
| 服务未配置 | `"搜索服务未配置，请联系管理员。"` |
| 请求超时 | `"搜索请求超时，请稍后重试。"` |
| 网络异常 | `"搜索网络异常: {详情}"` |
| 接口返回非 200 | `"搜索接口返回错误: HTTP {状态码}"` |
| 响应解析失败 | `"搜索响应解析失败，请稍后重试。"` |
| 业务错误码 | `"搜索服务返回错误，请稍后重试。"` |
| 无搜索结果 | `"未搜索到相关结果。"` |

工具内部捕获所有异常，不会向 Agent 抛出错误，始终返回友好的文本提示。

---

## 6. 使用要点

1. **必须调用工具**：回答实时性、时效性问题时必须调用 `bocha_web_search`，不要凭模型自身知识回答最新消息
2. **关键词精炼**：搜索关键词应简洁明了，去除口语化表述（如"今天有什么"可精炼为"今日科技新闻"）
3. **基于结果归纳**：工具返回结果列表后，应基于结果内容归纳回答，并按 `[n]` 序号标注引用来源
4. **来源自动透出**：引用来源（bocha_sum）由系统自动发送到前端并落库，无需模型在正文中罗列完整链接
5. **失败可降级**：搜索失败时向用户说明情况，可基于模型自身知识回答但需注明可能不是最新信息
