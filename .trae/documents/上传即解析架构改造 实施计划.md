# 上传即解析架构改造 实施计划

## 概要

把"文件先上传沙箱、问答时由 agent 调 mineru 技能解析"改为"**上传时后台即时解析、解析结果入库、问答时注入提示词**"：

1. **图片/文档/pdf/表格** → 上传时调 MinerU 解析 → 结果存 `upload_files` 表
2. **音频** → 上传时调音频转写模型（`Qwen3-ASR-1.7B`，OpenAI 兼容 `/v1/audio/transcriptions`）→ 转写文本存表
3. 意图识别通过后进入问答前，按 `session_id` 检索 `message_id IS NULL` 的记录，把解析内容**注入提示词**
4. 问答结束后，把本轮 user 消息的 `message_id` 回填到这些记录（避免下一轮重复注入）
5. **删除 mineru 技能工具链全部内容**（agent 运行时不再解析文件）

已确认的决策：
- **后台异步解析**：上传接口立即返回 200，`asyncio.create_task` 后台解析入库；问答时只注入已解析完成的
- **不再写沙箱**：上传文件不落 OpenSandbox/Docker 工作区，`upload.py` 移除沙箱/落盘分支
- **解析超时 60s**：超时后 `parsed_content` 诚实写入"解析超时，MinerU服务暂时无法解析该文件"（ASR 同理适配文案）

## 改动方案

### 任务A：建表 + DAO

**A1. [app/dao/init_mysql.py](file:///workspace/app/dao/init_mysql.py) 新增建表语句**（追加到 INIT_SQL，幂等）

```sql
CREATE TABLE IF NOT EXISTS upload_files (
    id             BIGINT AUTO_INCREMENT PRIMARY KEY,
    session_id     VARCHAR(64) NOT NULL,
    filename       VARCHAR(255) NOT NULL,
    media_type     VARCHAR(255) NOT NULL DEFAULT '',
    parse_type     VARCHAR(16) NOT NULL DEFAULT '',       -- mineru / asr / plain_text / none
    status         VARCHAR(16) NOT NULL DEFAULT 'pending', -- pending / parsing / completed / failed
    parsed_content MEDIUMTEXT NULL,
    error_message  VARCHAR(1024) NULL,
    message_id     BIGINT NULL,                            -- 上传时对话未开始，为 NULL
    created_at     TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at     TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```

索引：`CREATE INDEX idx_upload_files_session_msg ON upload_files(session_id, message_id);`（覆盖"按 session 查未绑定"与"回填"两类查询）

> 无外键：上传时 sessions 行尚不存在，外键会让 INSERT 失败。

**A2. 新建 `app/dao/upload_file_dao.py`**（仿 [action_audit_dao.py](file:///workspace/app/dao/action_audit_dao.py) 风格，aiomysql + DictCursor）

- `insert(session_id, filename, media_type, parse_type) -> int`：插入 pending 记录，返回 `cur.lastrowid`
- `mark_parsing(file_id)`：`UPDATE ... SET status='parsing' WHERE id=%s`
- `update_parse_result(file_id, status, parsed_content, error_message=None)`：写入解析结果
- `load_unbound_parsed(session_id) -> list[dict]`：`SELECT filename, parsed_content FROM upload_files WHERE session_id=%s AND message_id IS NULL AND parsed_content IS NOT NULL AND parsed_content != '' ORDER BY id`
- `bind_message_id(session_id, message_id)`：`UPDATE upload_files SET message_id=%s, updated_at=NOW() WHERE session_id=%s AND message_id IS NULL`

**A3. [app/main.py](file:///workspace/app/main.py)**：lifespan 中 `app.state.upload_file_dao = UploadFileDAO(mysql_pool)`（紧跟 action_audit_dao 之后）

### 任务C：解析服务（新建 `app/services/file_parse_service.py`）

核心职责：分类 → 解析 → 入库。**HTTP 提交/轮询逻辑从 [tools/mineru_tools.py](file:///workspace/tools/mineru_tools.py) 迁移**（改为直接传 bytes，不再读本地文件；超时从 300s 改为 `UPLOAD_PARSE_TIMEOUT`）。

```python
def classify_parse_type(media_type: str, filename: str) -> str:
    # audio/* 或扩展名 {.m4a,.mp3,.wav,.webm,.aac,.ogg,.flac} → "asr"
    # 图片/jpeg|png|gif|webp|bmp、pdf、doc(x)、xls(x)/csv、ppt(x) → "mineru"
    # text/plain 或 .txt/.md → "plain_text"
    # 其余 → "none"（只入库记录，不解析）
```

```python
async def parse_document_with_mineru(content: bytes, filename: str) -> str:
    # 迁移 mineru_tools 的提交+轮询逻辑：
    # - headers x-api-key；files={"file": (filename, content)}（bytes 直传）
    # - 轮询间隔 2s，总超时 UPLOAD_PARSE_TIMEOUT(60s)
    # - 超时返回 "解析超时，MinerU服务暂时无法解析该文件"
    # - 提交失败/任务失败/异常返回 "解析失败，MinerU服务暂时无法解析该文件"（附简要原因）
    # - 成功返回 md_content

    #   model=Qwen3-ASR-1.7B, file=(filename, content), prompt="解析音频", language="zh"
    # Authorization: Bearer {api_key}；httpx timeout=UPLOAD_PARSE_TIMEOUT
    # 响应 {"text": "..."} → 返回 text
    # 超时返回 "解析超时，音频解析服务暂时无法解析该文件"；异常同理

async def _parse_and_store(dao, file_id, content: bytes, filename: str, parse_type: str):
    # mark_parsing → 按 parse_type 分发解析 → update_parse_result(completed/failed)
    # 失败也诚实入库：status='failed' 且 parsed_content=失败/超时文案
    # Langfuse 埋点：get_current_langfuse().start_span("upload-parse")，
    #   input={filename, parse_type, size}，output={status, content_len, preview(前200字)}

async def start_background_parse(request, session_id, filename, media_type, content: bytes) -> int:
    # dao.insert(...) → asyncio.create_task(_parse_and_store(...)) → 返回 file_id
    # plain_text：直接 decoded = content.decode("utf-8", errors="replace") 入库（completed）

```

设计要点：
- **成功与失败都写 parsed_content**（成功=解析内容，失败/超时=文案），问答注入时 agent 能诚实告知用户"该文件解析失败"
- `none` 类型（如 ppt 解析前 mineru 支持 ppt？—— mineru 的 SUPPORTED_EXTENSIONS 不含 ppt/pptx，分类时 ppt/pptx 归 `none`）不注入
- Langfuse 用模块级单例 `get_current_langfuse()`（[app/services/langfuse_service.py](file:///workspace/app/services/langfuse_service.py)），upload 路由无需额外传参
